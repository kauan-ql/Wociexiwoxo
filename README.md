# Dark Hub | Mobile Panel

Dark Hub é um painel (GUI) para Roblox focado em **mobile**, com:
- Botão flutuante
- Sistema de abrir/fechar (toggle)
- Interface simples e leve
- Suporte a executores mobile (ex: Delta)

⚠️ Projeto educacional / experimental.

---

## 📱 Funcionalidades

- GUI arrastável
- Botão flutuante (toggle)
- Painel compacto (mini hub)
- Botões para executar scripts
- Pensado para celular

---
